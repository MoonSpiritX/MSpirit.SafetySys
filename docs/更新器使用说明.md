# 斜月安全管理系统 · 绿色版更新器（Updater.exe）使用说明

> 版本：1.0.0.0 ｜ 日期：2026-08-10 ｜ 文档更新：2026-08-11（①补充自动化打包脚本 make_full_msupd.py / make_incremental_msupd.py；②打包脚本改为"配置区 + 自动读版本 + 零交互"；③正式入档 docs/）

## 一、这是什么

`Updater.exe` 是斜月安全管理系统的**绿色版更新器**：

- **NativeAOT 单文件**（约 2.8MB），零运行时依赖，双击即用；
- 用于给已分发的绿色版做**增量更新**：解压 `.msupd` 更新包，按清单对账替换程序文件；
- 与项目存档 `.msarch` **完全无关**（一个是程序文件包，一个是项目数据包，勿混用）。

## 二、两种使用方式

### 1. 打包模式（发布新版本时用）

把「新版本程序文件夹」打成更新包：

```
Updater.exe --pack <程序文件夹> <输出.msupd>
```

示例：

```
Updater.exe --pack "D:\新版本程序" update_v1.2.0.0.msupd
```

- 会自动扫描文件夹内**所有文件**（排除 logs、*.msupd、Updater.exe 自身），生成全量文件清单 + SHA256 写入 `manifest.json`；
- 版本号自动读取 `MSpirit.SafetySys.dll` 的文件版本，无需手动填。

> **自动化打包（无弹窗，推荐脚本用）**：`Updater.exe --pack` 打包结束会弹确认框，阻塞自动化脚本。
> 需要脚本化打包时，用项目内两个 Python 脚本（逻辑与 `--pack` 等价，无任何弹窗）：
>
> **① 全量包**（清单对账，推荐发版用）：[`../其他文件/make_full_msupd.py`](../其他文件/make_full_msupd.py)
> ```
> python 其他文件/make_full_msupd.py <程序文件夹> <输出.msupd> <版本号>
> ```
> 示例：`python 其他文件/make_full_msupd.py "D:/新版程序/MSpirit.SafetySys" update_1.2.0.0.msupd 1.2.0.0`
>
> **② 增量包**（只覆盖同名文件，不删多余文件）：[`../其他文件/make_incremental_msupd.py`](../其他文件/make_incremental_msupd.py)
> ```
> python 其他文件/make_incremental_msupd.py <程序文件夹> <输出.msupd>
> ```
> 默认只打包主程序自身 4 个文件（`MSpirit.SafetySys.dll / .exe / .pdb / .runtimeconfig.json`），包体很小（约几 MB）；
> 仅当依赖库未变动时适用；若依赖 dll 有变化（如 NuGet 升级、跨版本大改），必须改用全量包。
>
> **日常发版推荐（双击，全程自动）**：双击「其他文件」下的 `打包全量更新包.bat` / `打包增量更新包.bat`：
> - **无需任何输入**——版本号自动从 `MSpirit.SafetySys.dll` 读取，文件名自动带版本号（如 `斜月安全管理系统_1.2.0.0.msupd`）；
> - 源文件夹、输出目录、包名前缀/后缀、扩展名、目标文件列表（增量）均在对应 `.py` 头部**【用户配置区】**修改（改项目换头部即可复用）；
> - 产物默认生成在「其他文件」目录；窗口打完自动停住显示结果。

### 2. 更新模式（分发到用户机器上）

把 `Updater.exe` 和 `.msupd` 更新包放到目标机器：

- **方式 A**：与 `MSpirit.SafetySys.exe` 同目录；
- **方式 B**：放任意目录，只要同目录或其第一层子文件夹内有 `MSpirit.SafetySys.exe`（例如绿色版根目录，主程序在子文件夹）。

双击 `Updater.exe`（或主程序内触发时加 `--silent` 参数静默执行）：

```
Updater.exe            ← 弹窗确认后更新
Updater.exe --silent   ← 全自动，不弹窗（供主程序自动更新调用）
```

### 3. 两种更新模式（按包内容自动识别）

更新器按更新包内是否含 `manifest.json` 自动选择模式：

| 包内有无 manifest.json | 模式 | 行为 |
|---|---|---|
| 有（`Updater.exe --pack` 生成） | **全量对账** | 解压 + SHA256 校验 + 按清单覆盖/新增/**删除多余旧文件** |
| 无（手工打包的纯文件 zip） | **增量覆盖** | 仅解压并**覆盖同名文件**，不删除任何文件，不校验哈希 |

增量包制作示例（手工打包，不带 manifest）：

```
把要更新的文件按相对路径放入 zip（如 MSpirit.SafetySys.dll、Resources\xxx.html）
```

> 无论哪种模式，zip slip 防护（防 `..` 逃逸）、进程占用检查、失败回滚都生效。

## 三、更新流程（内部做了什么）

1. 定位程序文件夹（含 `MSpirit.SafetySys.exe` 的目录，同目录优先、子文件夹兜底）；
2. 查找更新包（同目录 → 程序文件夹，多个取最新）；
3. 提示确认（静默模式跳过）；
4. **等待主程序退出**：若主程序仍在运行，先通过命名管道请求其**保存数据并自动退出**（主程序启动时监听 `MSpirit.SafetySys.Update` 管道，收到 save-exit 命令后保存视图状态/记录并正常退出），再轮询等待 ≤15 秒；仍不退才提示用户手动关闭；
5. 读取 `manifest.json`（全量模式）+ 解压到临时目录 + **SHA256 完整性校验**（全量模式）；
6. 备份旧文件 → 复制新文件 → **清单对账删除**多余文件（全量模式）/ 仅覆盖同名文件（增量模式）；
7. 失败自动回滚；成功清理备份，询问是否重启主程序（静默模式不重启）。

> **主程序侧配合**：`Services/UpdateIpcService.cs` 在应用启动时启动管道监听（后台线程），收到 `save-exit` 后调度到 UI 线程执行 `MainWindow.SaveAndExitForUpdate()`（清焦点提交绑定 → 保存记录 → 保存视图状态 → 正常退出）。**主程序 1.0.0.1 起已支持自动保存退出**（1.0.0.0 旧版无监听，更新器将提示手动关闭）。

## 四、替换规则（清单对账式）

| 情况 | 处理 |
|---|---|
| 包内文件、程序文件夹已有 | 覆盖更新 |
| 包内文件、程序文件夹没有 | 新增 |
| 程序文件夹有、包内没有（多余旧文件） | **删除**（保持新旧版本文件集合一致） |
| `logs\` 目录 | 始终保留（日志） |
| `*.msupd` 包、`Updater.exe` 自身 | 始终保留 |

> 注意：程序数据在 `MSpirit.SafetySys.Date`（非系统盘或用户目录 `%USERPROFILE%` 下），**不在程序文件夹内**，更新不影响任何用户数据。

## 五、安全防护

- **zip slip 防护**：解压时校验路径，禁止 `..` 逃逸出目标目录；
- **完整性校验**：包内每个文件比对 manifest 中的 SHA256 与大小，不一致即拒绝更新；
- **失败回滚**：替换前先备份，任一环节失败自动恢复原状。

## 六、发布检查清单（发新版时）

1. `dotnet publish MSpirit.SafetySys.Updater -c Release -p:PublishProfile=FolderProfile`
   → 产物 `bin\Release\Updater\Updater.exe`
2. 发布新主程序：`dotnet publish MS_SafetyManagementSystem.csproj -c Release -r win-x64 --self-contained true -o <临时目录>`（升版本号只需改根 `Directory.Build.props` 的 `SafetySysVersion`，主程序/启动器/更新器三者自动跟随）；
3. 打包更新包（选一，均无弹窗限时可优先用脚本）：
   - `Updater.exe --pack <新程序文件夹> <版本号>.msupd`（交互式，结束弹确认框）
   - `python 其他文件/make_full_msupd.py <新程序文件夹> <版本号>.msupd <版本号>`（全量，自动化）
   - 依赖库未变时可用 `python 其他文件/make_incremental_msupd.py <新程序文件夹> <版本号>_inc.msupd`（增量，包小）
4. 分发：`Updater.exe` + `*.msupd` 两个文件，放到用户绿色版根目录；
5. 提醒用户：双击 `Updater.exe` 即可更新（更新器会自动请求主程序保存退出并等待；1.0.0.1 及以上主程序支持自动保存退出，旧版需手动关闭）。

## 七、已知限制

- 更新包是**全量清单**（打包时包含程序文件夹所有文件），所以包体积与程序文件夹相当；
- 更新器自身（Updater.exe）不在更新范围内，如需升级更新器需单独分发；
- 仅支持 win-x64。
