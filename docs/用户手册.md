# 用户手册

> 适用范围：斜月安全管理系统（MS_SafetyManagementSystem，个人版，当前版本 **1.2.0.0**，以「设置 → 关于软件」显示为准）
> 面向：日常使用本系统的操作人员。系统为单机桌面应用，数据保存在本机。

## 1. 快速上手

1. 双击 `斜月安全管理系统.exe`（绿色版启动器）启动；或直接运行程序文件夹下的 `MSpirit.SafetySys.exe`（开发调试可从 Visual Studio 按 F5 运行）。
2. 首次使用会自动创建项目；如已有数据，启动后进入上次使用的项目。
3. 顶部菜单「项目列表 → 新建项目 / 项目及存档管理」可创建或切换项目。
4. 菜单「模块」可切换 **隐患管理** 与 **人员管理** 两大模块。

> 提醒：程序会在启动和退出时自动备份数据（保留最近 30 天、最多 100 份）；如需长期备份，见第 9 节。

## 2. 主界面

- **顶部菜单栏**：
  - **项目**：新建项目、项目及存档管理；
  - **模块**：隐患管理 / 人员管理；
  - **设置**：图片查看器设置、常用隐患类型管理、常用链接管理、使用提示、关于软件（含更新日志）、关闭程序；
  - **办公工具**：图片处理、手机图片传输。
- **左侧分组树**：显示当前项目的分组结构（隐患：年份月份 → 日期；人员：单位 → 部门）。
- **中间记录卡区域**：以卡片形式展示当前分组的记录，可横向排列、滚动浏览。
- **顶部功能区**（记录卡区域上方）：新建分组、添加日期、添加卡片、清空卡片、删除记录、数据管理、数据分析。
- **窗口拖拽**：程序大部分窗口（图片处理、手机图片传输、使用提示、关于软件、项目及存档管理等）的**空白区域**按住左键即可拖动窗口，便于多窗口操作。

## 3. 项目管理

- **新建项目**：菜单「项目列表 → 新建项目」，输入名称即可。系统会自动创建独立的项目数据库与附件目录。
- **管理项目**：菜单「项目列表 → 项目及存档管理」，可切换当前项目、重命名、调整排序、删除项目。
- **存档导出/导入**：在「项目及存档管理」窗口勾选项目后点击「导出选中项目」，生成 `.msarch` 存档包（含项目数据与附件，可用于备份或迁移到其他电脑）；点击「导入存档」可将 `.msarch` 存档恢复到本机。
- **切换模块**：菜单「模块 → 隐患管理模块 / 人员管理模块」，或使用界面上的模块切换入口。

## 4. 隐患管理

### 4.1 分组

- 分组为两级：**年月分组**（如 `2026年07月`）→ **日期分组**（如 `07月03日`，可附带标签区分同日不同分组）。
- 使用功能区「新建分组」「添加日期」按钮创建分组；在分组树上右键也可进行相关操作。

### 4.2 记录卡

- 点击「添加卡片」在当前分组新建一张空白记录卡。
- 卡片字段：责任单位、责任人、隐患位置、隐患类型、级别、整改期限、完成日期、复查人、隐患描述、整改措施。
- **自动保存**：卡片内容输入即保存，无需手动保存按钮。

### 4.3 图片

- 每张卡片最多 **6 张图片**：隐患照片 3 张 + 整改照片 3 张。
- 添加方式：将图片**拖拽**到照片区域，或**右键**照片区域选择添加。
- 点击照片可打开内置图片查看器查看原图。
- 复制卡片时图片会一并复制到目标日期；个别图片源文件缺失时会提示具体哪几张未能复制。

### 4.4 卡片右键菜单

| 菜单项 | 说明 |
|---|---|
| 生成图片 | 把当前记录卡内容导出为一张 PNG 图片（便于分享/存档） |
| 清空卡片 | 清空当前卡片的全部内容 |
| 删除卡片 | 删除当前卡片（不可恢复） |
| 移动卡片 | 把卡片移动到本月另一日期分组 |
| 复制卡片 | 复制一张到本月另一日期分组（内容与图片一并复制） |

### 4.5 状态

卡片状态分为：**完成 / 超期 / 进行 / 无效**，按实际整改进展维护。

## 5. 人员管理

### 5.1 分组与卡片

- 分组为两级：**单位** → **部门/班组**。
- 「添加卡片」在当前部门新建人员卡片；字段含姓名、性别、年龄、籍贯、身份证号、证件信息、手机号等。
- 支持添加身份证照片与证书照片附件。

### 5.2 局域网批量录入（手机扫码 + OCR）

在人员模块，对**部门/单位分组右键 → 批量人员录入**，打开录入窗口：

1. 点击「启动服务」，界面生成**二维码**（含本机局域网地址）。
2. 手机连接与电脑**同一局域网**，扫码打开录入页面。
3. 手机拍照身份证正反面，系统通过 OCR 自动识别并录入该部门下的人员卡片。
4. 窗口实时显示「已连接设备：x台」与「已录入：x人」两行计数（设备断开即时更新，无需等超时）。

隐患模块类似：对**年月分组右键 → 隐患手机录入**（窗口「手机录入隐患数据」），可手机拍照录入隐患卡片，计数显示「已连接设备」与「已录入：x条」。

> 注意：仅限同一局域网内设备访问；二维码随服务启停生成/隐藏。

### 5.3 人员统计分析

在人员模块点击功能区「数据分析」，可查看按单位/部门的人员统计图表（学历、证件到期、三类人员等）。

## 6. 图片查看器

- 在卡片上**点击照片**即可用内置图片查看器打开（支持多张连看、缩略图、幻灯片）。
- 查看器类型可在「设置 → 图片查看器设置」切换：内置查看器（全屏/普通窗口）或系统默认查看器。

### 快捷键

| 按键 | 功能 |
|---|---|
| 滚轮 | 缩放图片 |
| 双击图片区域 / Enter | 切换全屏 |
| ← / → | 上一张 / 下一张 |
| ↑ / ↓ | 放大 / 缩小 |
| Space | 重置缩放与位置（全屏时居中贴合屏幕） |
| F11 / F12 | 逆时针 / 顺时针旋转 90° |
| F9 / Shift+F9 | 水平翻转 / 垂直翻转 |
| Backspace | 重置旋转与翻转 |
| 0 | 窗口尺寸贴合图片（仅非全屏） |
| F5 / F6 | 从当前 / 从第一张开始幻灯片（F5 再按可停止） |
| F7 / F8 | 幻灯片播放速度 减 / 增 |
| Esc | 停止幻灯片（未播放时关闭查看器） |
| Ctrl+C | 复制当前图片到剪贴板 |
| Delete | 删除当前图片（会删除对应附件文件，请谨慎） |

> 另外支持把图片或文件夹直接拖入查看器窗口（文件夹将以幻灯片方式播放）。

## 7. 数据管理（导入 / 导出）

点击功能区「数据管理」打开数据管理窗口：

- **导出**：按 Word / Excel 模板导出当前模块数据（字段自动智能匹配），可生成隐患整改报告书等文档。
- **导入**：从 Word / Excel 模板导入数据，自动匹配字段并创建记录。

> 模板字段名称与系统字段存在别名映射，导入前建议先用模板导出一次参考格式。

## 8. 办公工具与其他功能

### 8.1 图片处理（方向转换 / 标注与剪裁）

菜单「办公工具 → 图片处理」或托盘「办公工具 → 图片处理」打开。窗口左侧导航提供两个面板：

**方向转换**面板：

- **导入图片**：点「添加文件」多选，或点「添加文件夹」整目录导入，也可以直接把图片/文件夹**拖入窗口**；自动去重，大文件夹快速加载不卡界面。
- **6 种操作**：左转90°、旋转180°、右转90°、水平翻转、垂直翻转、**校正方向**（按照片 EXIF 方向信息自动摆正，适用于手机/相机直出照片）。
- **执行**：选择操作 → 点「开始执行」，后台批量处理，进度条显示进度，可随时「取消」；失败文件会列出提示。
- **输出**：与原图片格式一致（PNG/JPG/JPEG/BMP/WEBP/TIFF/GIF），保存在原目录；同名文件自动加序号，**不会覆盖原图**。
- 重复执行时状态列自动复位为"待处理"，始终反映本次执行结果。

**标注与剪裁**面板：
- **图片列表**：添加文件/文件夹或直接拖入，图片按所在文件夹自动分组（可折叠）；点选后在右侧预览。
- **裁剪**：在预览图上拖拽裁剪框（8 个手柄缩放、框内拖动整体平移、选区外半透明遮罩），支持锁定比例（自由 / 1:1 / 3:4 / 4:3 / 9:16 / 16:9）；状态栏实时显示像素选区。
- **标注**：点选标注工具后在图上拖拽绘制——矩形 / 圆形 / 直线 / 箭头（按所选颜色与线宽描边）、文字（绘制后弹出就地输入框）、**马赛克**（拖出矩形区域即像素化遮挡，预览与输出均为真实马赛克效果）；画完自动回到选择模式，点击标注可选中（高亮边框 + 右上角 ✕ 删除）、拖动移动、按 Delete 键删除。
- **标注样式**：标注颜色 8 色、字号 10~60 号、线宽 4 档，作用于新绘制的标注。
- **输出**：「应用」按裁剪选区输出——**另存至原目录**（`原名_Edit.ext`，不覆盖原图）/ **另存至其他位置**（选择文件夹）/ **覆盖原图**（原图移入回收站后保存）；「应用并下一张」连续处理，保存后列表自动刷新。

### 8.2 手机图片传输

菜单「办公工具 → 手机图片传输」或托盘「办公工具 → 手机图片传输」打开。用途：**手机照片无线传到电脑**，现场拍摄的照片回办公室秒传，不用插线、不用网盘。

1. **选择保存位置**：左侧位置列表默认「用户-图片」文件夹，可「添加自定义位置」；也支持直接把文件夹**拖入窗口任意位置**添加。
2. **启动服务**：点「启动服务」生成二维码（含本机局域网地址）；右侧文件列表实时显示已接收图片（序号/拍摄时间/文件名/大小）。
3. **手机操作**：手机连接**与电脑同一局域网**，扫码打开页面 → 拍照或从相册多选 → 点上传（原图直传、浏览器不压缩），传完有完成提示。
4. **自动归档**：图片按**拍摄日期**自动分文件夹存放（如 `2026-08-12\`）；无拍摄日期的（截图/微信图等）按手机上的文件生成日期归类；都没有的归入上传当天。
5. 传输列表支持**双击打开图片**、**右键打开文件位置**（不依赖服务状态）。

> 提示：手机端保持原图直传，不压缩、不修改原始信息。iPhone 用户若照片为 HEIC 格式，请在相机设置中选「兼容性最佳」（输出 JPG）。服务仅限同一局域网访问，关闭窗口即停止。

### 8.3 系统托盘与多级菜单

- 点窗口 **X** 或「设置 → 关闭程序 → 最小化到托盘」时，程序收缩到系统托盘后台常驻（数据仍自动保存）。
- **右键托盘图标**弹出多级菜单（主窗口未展开也能快捷使用）：
  - **显示主窗口**：恢复主界面；
  - **办公工具**：图片处理、手机图片传输（主窗口保持隐藏，工具独立弹出）；
  - **信息官网 / 外部AI / 快捷网址**：对应「常用链接管理」中的分类链接，悬停展开后点击直接用浏览器打开；
  - **退出程序**：保存数据后完全退出。

### 8.4 关闭程序

菜单「设置 → 关闭程序」弹出提示窗口，两种选择：

- **最小化到托盘**：程序转入后台运行，可从托盘图标恢复；
- **退出程序**：先保存当前数据，再完全退出。

> 无论哪种退出方式，数据都会自动保存；直接点窗口 X 等同于「最小化到托盘」。

### 8.5 常用隐患类型管理 / 常用链接管理

- **常用隐患类型管理**：菜单「设置 → 常用隐患类型管理」，维护隐患记录卡快捷选择的类型列表（支持勾选启用/停用、整体启用）。
- **常用链接管理**：菜单「设置 → 常用链接管理」，维护三类网址（政府信息官网 / 外部AI官网 / 自定义网址），保存后主菜单与**托盘菜单**同步生效。

### 8.6 四季主题与节气

界面背景随季节自动切换（春/夏/秋/冬），日历视图显示二十四节气。

## 9. 数据备份与常见问题

### 备份

- 数据根目录默认：第一个可用的非系统固定盘（D→E→F…字母序，数据根为 `{盘根}\MSpirit.SafetySys.Date`）；无可用非系统固定盘时为 `%LOCALAPPDATA%\MSpirit.SafetySys.Date`。
- **数据目录找回**：若程序启动时提示"未找到上次使用的数据目录"（如移动硬盘/分区未连接、盘符变化），可选择「手动选择目录」指定原数据所在位置，或「搜索其他位置」自动全盘查找，找回后数据完整恢复。
- **自动备份**：程序在启动和退出时会自动把数据库与配置备份到数据根目录下的 `ProjectsDate.Backup` 文件夹（自动保留最近 30 天、最多 100 份），日常使用无需手工备份。
- **长期/手动备份**：如需更稳妥的长期备份，可在退出程序后整体复制数据根目录（含 `master.db`、`ProjectsDate` 等）；也可在「项目及存档管理」中导出 `.msarch` 存档包保存到其他位置。
- 恢复方法：整体备份可将目录放回原位置；`.msarch` 存档通过「项目及存档管理 → 导入存档」恢复。

### 常见问题

| 问题 | 处理 |
|---|---|
| 复制卡片提示"图片未能复制" | 对应源图片文件可能已缺失，按提示确认具体图片；源文件无法恢复 |
| 手机无法打开扫码页面 | 确认手机与电脑在同一局域网；确认服务已启动 |
| 程序异常弹窗 | 程序目录下 `logs\debug*.log` 会记录详细异常，可提供该日志排查 |
| 界面显示异常/卡顿 | 先尝试重启程序；数据不会因重启丢失 |

## 10. 程序更新

- **查看版本**：「设置 → 关于软件」中显示程序版本与更新日志（当前版本 **1.2.0.0**）。
- **如何更新**：拿到新版更新包（`*.msupd` 文件）与 `Updater.exe` 后，放到绿色版根目录（与 `斜月安全管理系统.exe` 同一文件夹），**双击 `Updater.exe`**：
  1. 自动找到更新包并提示确认；
  2. 若主程序正在运行，更新器会自动请求其保存数据并退出（当前版本已支持自动保存退出）；
  3. 校验文件完整后替换程序文件（旧文件自动备份，失败自动回滚）；
  4. 完成后按提示重新启动程序即可。
- **更新不影响数据**：程序数据保存在数据根目录（默认 `D:\MSpirit.SafetySys.Date`），不在程序文件夹内，更新前后数据均不受影响。
- 更新器支持跨版本更新（全量对账替换，会自动删除旧版本多余文件）。
